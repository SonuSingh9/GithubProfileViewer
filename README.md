GitHub Profile Viewer - HTML, CSS, JavaScript

Project Overview :-
This web application allows users to search for GitHub profiles and view detailed information fetched via the GitHub API. Users can enter a GitHub username and retrieve profile details, repositories, followers, and following statistics. The application is designed to be fully responsive for seamless use across different devices.

Features :-
  - GitHub Profile Search: Users can search for any GitHub username.
  - Profile Details: Displays avatar, bio, and other GitHub profile details.
  - Repository List: Showcases public repositories with names and descriptions.
  - Followers & Following: Provides direct links to followers and following lists.
  - Responsive Design: Ensures smooth usage on desktops, tablets, and mobile devices.


Technologies Used :-
  - Frontend: HTML, CSS, JavaScript
  - API Integration: GitHub API for fetching profile data
  - Styling: CSS for layout and responsiveness
  - Logic Implementation: JavaScript for handling API calls and displaying data


    Installation & Setup
   1. Clone the repository from GitHub :-
        (git clone https://github.com/SonuSingh9/GithubProfileViewer.git)
  2. Navigate to the project directory :-
        (cd GithubProfileViewer)

  Usage :-
   - Enter a GitHub username in the search input field.
   - Click the search button to fetch and display profile details.
   - View user information, repositories, followers, and following.
